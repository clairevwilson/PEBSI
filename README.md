The Python Energy Balance model for Snow and Ice (PEBSI) is an open-source, distributed glacier energy balance model that simulates the surface energy balance and subsurface mass balance using GPU or CPU parallelization. Snow albedo is simulated from physical properties using a neural network emulator of the Snow, Ice and Aerosol Radiative transfer model, SNICAR.

For help getting started with the model, please refer to the [User guide](https://pebsi.readthedocs.io/en/latest/).

For information on the model physics and functionality, please refer to the [Technical reference](https://docs.google.com/document/d/1skLi2KsmpXVVr0Mw3aYVu41SMf5OGHMGAQyU9AGE_iM/edit?tab=t.0#heading=h.bdo995lcdgk2).
